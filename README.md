# Python & Data Analysis Basics

A collection of practice Jupyter Notebooks covering core Python programming, object-oriented programming, and basic data analysis using NumPy and Pandas.

## What's Inside

* **`01_Fundamental.ipynb`** – Core Python concepts: variables, loops, conditions, and functions.
* **`02_Classes.ipynb`** – Object-Oriented Programming (OOP): creating classes and methods.
* **`03_Pandas_l.ipynb`** – Data manipulation: arrays with NumPy, tables with Pandas DataFrames.

## Tools Used

* **Language:** Python
* **Libraries:** NumPy, Pandas
* **Environment:** Jupyter Notebook / VS Code
